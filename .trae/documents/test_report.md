## 3. 问题澄清

### 3.1 关于"NaN"错误的说明

**之前测试失败的原因**：测试数据**缺少了 `price` 字段**：

```powershell
# ❌ 错误测试数据
$body = @{table_id=38; items=@(@{dish_id=4; quantity=2})}
# item.price = undefined → undefined * 2 = NaN
```

**小程序正确做法**（`cart.js` 第210-215行）：
```javascript
items.push({
  dish_id: dish.id,
  dish_name: dish.name,
  price: parseFloat(dish.price),  // ✅ 确保是数字类型
  quantity: count
});
```

**结论**：小程序端代码正确，下单功能正常工作。之前的错误是测试数据不完整导致的。

### 3.2 小程序实际下单流程

```
选菜 → syncCartToBackend() → POST /orders/sync-draft (创建草稿) 
         ↓
确认页 → POST /orders/:id/status (状态: draft → submitted)
```

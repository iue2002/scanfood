                                              扫码点餐工程改进 总览
                    从 feature → 逐渐加固工程底座

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    一、第一阶段：安全底线（P0）

    P0-1  关闭高权限注册漏洞
                ↓ /auth/register 强制限 customer 角色
                ↓ 员工创建统一走 POST /merchant-ops/employees

    P0-2  后端 RBAC 权限守卫（共 60+ 端点）
                ↓ 7 个 Controller 补齐 @Permissions 装饰器
                ↓ customer / waiter / cashier / manager / owner 五级隔离
                ↓ 权限矩阵固化为唯一真相源

    ─── 附 ───  清理敏感日志（openid / JWT 明文过滤）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    二、第二阶段：订单可靠性（P0 + P1）

    P0-3  订单写入事务化
                ↓ createOrder / syncAddMore / updateOrderStatus 等 8 方法
                ↓ 全部进 db.transaction → WS/通知/打印全部事务外
                ↓ 结账成功 ⇔ 订单 settled + 桌台 idle 同事务保证

    P0-4  订单/加菜/结账幂等
                ↓ 新增 idempotency_keys 表
                ↓ 小程序 + admin-web 双端发送 idempotency_key
                ↓ 重复点击 / 弱网重试 → 只产一个订单 / 一条加菜记录

    P1-3  抽取 OrderLifecycleCore
                ↓ 订单状态流转规则集中一处（活跃判定 / 加菜 / 结账 / 上菜 / 桌台释放）
                ↓ 后续加状态只改 Core

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    三、第三阶段：MySQL Outbox（P1）

    P1-1  MySQL Outbox 事件投递箱
                ↓ 新增 event_outbox 表
                ↓ ORDER_CREATED / ADD_MORE / SETTLED 等事件写入事务
                ↓ OutboxScheduler 定时消费 → WS 推送 / 通知 / 打印
                ↓ 事件失败可重试、可追踪，进程崩溃不丢事件

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    四、第四阶段：内存状态 MySQL 化（P1）

    P1-2  MySQL TTL Store（替换内存 Map）
                ↓ 新增 ttl_kv_store 表 + TtlStorePort 抽象
                ↓ 验证码 token → MySQL TTL
                ↓ 登录失败计数 + 账号锁定 → MySQL TTL
                ↓ 服务重启后锁定状态不丢失

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    五、审计与安全加固（P1）

    P1-4  审计覆盖所有关键写操作
                ↓ 6 个 Controller / 27 个写端点加 @Audit() 装饰器
                ↓ dishes · tables · orders · refunds · store-settings · notif
                ↓ 与既有 audit_logs 表 + AuditInterceptor 无缝对接

    P1-5  上传安全加固
                ↓ 禁止 SVG 上传（防 XSS 风险）
                ↓ 魔数字节签名校验（防 MIME 类型伪造）
                ↓ 新增 image_assets 表（上传元数据追踪 + 孤儿清理预备）
